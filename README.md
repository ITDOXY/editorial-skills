# editorial-skills

Переносимые Skills **research** и **article-review** для AI-редакции: исследование источников, проверка фактов и редакционное ревью по правилам вашего проекта.

## Состав

- `skills/research/` — исследование, правила доказательств и шесть шаблонов досье.
- `skills/article-review/` — ревью и чек-лист.
- `tools/editorial_package.py` — явная установка, проверка, обновление, откат и восстановление.
- `examples/minimal-project/` — самостоятельный английский пример с вымышленным FrameNote.
- `tests/` — проверки установщика.

Все инструкции, шаблоны и контракт профиля находятся в этом пакете. Настройка и работа описаны в документации и минимальном примере; состав и версии перечислены в [описании пакета](docs/package.md).

Имена установленных Skills сохраняются: `.agents/skills/research/` и `.agents/skills/article-review/`. С ними копируются ресурсы и лицензионные уведомления. Сценарии создания и обновления статей остаются в вашем проекте; этот пакет не пишет статью автоматически при установке.

## Начало работы

1. Подготовьте `editorial.config.yaml` и пять документов правил по [контракту профиля](docs/profile.md). Пути, язык, генератор и тема задаются потребителем. Минимальный пример использует обычный Markdown. Проверки генератора и темы опишите в testing_profile.
2. Создайте отдельное Python-окружение и установите `requirements.txt`. Нужны Python 3.9+ и PyYAML 6.0.3; для режима commit также Git CLI.
3. Выполните [установку в копию проекта](docs/install.md). Выберите установку из локальной папки или по полному SHA коммита.
4. В новом Local-чате Codex подтвердите обнаружение обоих проектных Skills по фактическим путям и примените их к [примеру](examples/minimal-project/README.md). Наличие файлов само по себе не доказывает обнаружение приложением.
5. Согласуйте план до записи статьи. Ревью, принятие плана и завершение задач не разрешают автоматические коммиты, push или публикацию.

```sh
python3 -m unittest discover -s tests -v
```

Ограничения, повтор/откат и режим полного SHA описаны в [руководстве установки](docs/install.md). Материалы исследований, исходные статьи и редакционные правила проекта сохраняются; пути, язык и требования к проверкам задаются его профилем.
