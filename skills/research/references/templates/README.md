# Шаблоны досье

Скопируйте brief.md, sources.yaml, findings.md, outline.md, verification.md и review.md в dossier_root/<article-id>/ из профиля. Сам README не копируется. Сохраняйте один article-id при повторе и продолжении.

Заполнители заменяются известными значениями. Неизвестное отмечайте явно. Новое досье имеет provenance new и reconstructed_at null. Восстановленное досье имеет provenance reconstructed и дату восстановления. Sources schema_version 1 сохраняет Source ID, findings сохраняет Claim ID. Решение редактора записывается отдельно от хешируемого предложения.

Используйте нормативные документы профиля. Приватные входы остаются вне публичного репозитория. Старое досье не перезаписывается пустыми шаблонами.
