# Состав пакета

editorial-skills содержит два Skill: research для исследования источников и article-review для проверки материалов по правилам проекта.

## Компоненты

- skills/research/: инструкции, контракт профиля, правила доказательств и шесть шаблонов досье.
- skills/article-review/: инструкции и чек-лист ревью.
- tools/editorial_package.py: установка, проверка, обновление, откат и восстановление.
- examples/minimal-project/: минимальный Markdown-проект с вымышленным форматом FrameNote.
- tests/: проверки установщика и Git-адаптера.
- docs/: настройка профиля, установка и лицензирование.

Пути, язык, правила согласования, генератор и тема определяются профилем потребителя. Все необходимые инструкции, ресурсы и шаблоны находятся внутри пакета. Внешние зависимости объявлены отдельно.

## Версии и контроль состава

Версия пакета определяется в package-manifest.json. Версии профиля и досье — 1. package-manifest.json содержит SHA-256 16 устанавливаемых файлов, включая LICENSE/NOTICE обоих Skills. [package.json](package.json) содержит метаданные, хеши шести шаблонов и сведения о стандартном тексте лицензии.
